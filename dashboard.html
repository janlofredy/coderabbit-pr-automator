📖 How to Set Up Each Authentication Type

Method 1: Direct Docker CLI Login (OAuth / Google / GitHub) Docker CLI
  1. Open your terminal and run the Docker command directly (replace account2 with any name): 
    docker exec -it coderabbit-pr-automator sh -c 'HOME=/app/data/config/accounts/account2 coderabbit auth login'
  2. The CLI will print an OAuth URL or prompt for login. Complete sign-in in your browser with your secondary Google/GitHub account.
  3. The profile credentials are saved directly into persistent container storage (/app/data/config/accounts/account2).
  4. Click 🔄 Recheck above — the dashboard auto-discovers the new profile account and adds it into rotation automatically!
Method 2: CodeRabbit API Key (Direct UI / Headless) Headless
  1. Log in to CodeRabbit.ai in your browser with your desired account.
  2. In settings, generate an Agentic / CLI API Key.
  3. Click Add Another CodeRabbit Account above, paste the API key, select your region, and save.
  4. You can test the credentials immediately with the Test button on the account card!
Method 3: Default Host Login (Automatic Fallback)

If no additional accounts are configured, the service uses the default ~/.coderabbit directory mounted at container startup (or /DATA/AppData/coderabbit/coderabbit-cli in CasaOS).

🐙 GitHub Authentication & Token Guide

Checking connection…

CodeRabbit Auto-Reviewer requires a GitHub Personal Access Token (classic) to discover pull requests, fetch code diffs, submit reviews, and approve clean changes.

Quick Setup: 1-Click Link 🔗 Generate on GitHub ↗
  1. Click the button above to open GitHub with repo scope pre-selected.
  2. Choose an Expiration (e.g., 90 days or No expiration).
  3. Ensure repo is checked (or public_repo for public projects).
  4. Click Generate token at the bottom of the page.
  5. Copy the token (starts with ghp_) and paste it into Settings.

⚙️ Service Configuration & Settings

Settings are saved to persistent storage and take effect immediately. GitHub credentials are stored separately from config.json and never shown again after saving.
