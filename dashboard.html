🐰 CodeRabbit Auth Status

Checking CLI status…

Google browser sign-in must run on the Docker host because CodeRabbit CLI browser OAuth is unavailable inside Docker/CI.

  1. Open a terminal on the machine running Docker.
  2. Install the CodeRabbit CLI there if needed.
  3. Run coderabbit auth login and choose Continue with Google in the browser.
  4. Verify with coderabbit auth status. The default Compose setup mounts that host's ~/.coderabbit automatically.

For CasaOS, authenticate on another machine, then copy the CLI state into /DATA/AppData/coderabbit/coderabbit-cli.

For headless API-key authentication, run docker exec -it coderabbit-pr-automator coderabbit auth login --api-key "<key>". CLI auth reference

🐙 GitHub Authentication & Token Guide

Checking connection…

CodeRabbit Auto-Reviewer requires a GitHub Personal Access Token (classic) to discover pull requests, fetch code diffs, submit reviews, and approve clean changes.

Quick Setup: 1-Click Link 🔗 Generate on GitHub ↗
  1. Click the button above to open GitHub with repo scope pre-selected.
  2. Choose an Expiration (e.g., 90 days or No expiration).
  3. Ensure repo is checked (or public_repo for public projects).
  4. Click Generate token at the bottom of the page.
  5. Copy the token (starts with ghp_) and paste it into Settings.

⚙️ Service Configuration & Settings

Settings are saved to persistent storage and take effect immediately. GitHub credentials are stored separately from config.json and never shown again after saving.
